HushArt Armenian Top Store կայք — HTML/CSS/JavaScript

1. Բացեք այս պանակը Visual Studio Code-ում։
2. Բացեք index.html-ը բրաուզերում կամ Live Server-ով։
3. Փոխեք assets/ նկարները իրական աշխատանքների լուսանկարներով։
4. Կայքի տեքստերը խմբագրեք index.html-ում։

Նշում. նկարները կտրված են տրամադրված դիզայնի մակետից, ուստի ցուցադրական են։ Կայքը ստատիկ է, առանց սերվերի/պատվերների բազայի։
