# HushArt Armenian Top Store — 3D մոդելներ

1. Բացեք `index.html` Live Server-ով և ընտրեք «3D մոդելներ»։
2. Առանձին էջը՝ `3d-models.html`։ Գները չեն ցուցադրվում։
3. Նկարները տեղադրեք `assets/images/3d-models/` պանակում։
4. `models-data.js` ֆայլում փոփոխեք `image`, `title`, `id`, `type`, `description` դաշտերը։ HTML փոփոխելու կարիք չկա։
5. Ներկայիս չորս SVG պատկերները **սխեմատիկ ցուցադրական օրինակներ են**, ոչ իրական արտադրանքի լուսանկարներ և ոչ պտտվող 3D մոդելներ։
6. Այս տարբերակը ցուցադրում է 3D ռենդերի նկարների կատալոգ։ Իրական պտտվող 3D-ի համար պետք են `.glb` / `.gltf` ֆայլեր և համապատասխան դիտարկիչի ինտեգրում։
7. «Պատվիրել նմանատիպ աշխատանք» կոճակը բացում է email ծրագիրը՝ մոդելի համարով։ Ուղիղ կայքից ուղարկելու համար պետք է backend կամ form ծառայություն։


ՆՈՐ ՆԿԱՐՆԵՐ. complex-01.jpg ... complex-08.jpg կտրատված են օգտատիրոջ տրամադրած արտաքին կայքի սքրինշոթից: Հրապարակման համար օգտագործեք միայն ձեր սեփական կամ արտոնված լուսանկարները: Փոխարինելու համար պատկերը պահեք assets/images/3d-models/ և փոխեք models-data.js-ի image դաշտը: Նկարները սովորական 2D լուսանկարներ են, ոչ 360° պտտվող 3D ֆայլեր։
