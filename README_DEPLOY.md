# HushArt Armenian Top Store — տեղադրում և փորձարկում

**Անվանումը:** HushArt Armenian Top Store։ Գլխավոր էջի ընտրված բեժ ոճը պահպանված է։

## Տեղային գործարկում

1. Տեղադրեք Node.js 18+։
2. VS Code-ով բացեք այս պանակը։
3. Windows PowerShell-ում գրեք `$env:ADMIN_PASSWORD="YourUniqueStrongPassword123!"` (փոխեք ձեր գաղտնաբառով)։
4. Նույն տերմինալում գրեք `npm start`։
5. Բացեք `http://localhost:3000` և ադմին-բաժինը՝ `http://localhost:3000/admin`։

**Մի օգտագործեք Live Server պատվերների/ադմինի համար.** այն չի աշխատեցնում Node.js API-ն։

## Աշխատանքներ ավելացնել

Ադմին-բաժնից ավելացրեք անուն, կոդ, կատեգորիա, նյութ, չափեր և մինչև 5 լուսանկար։ Նկարները հասանելի են `/api/work-image/...` հասցեով։ Հաճախորդների պատվերին կցված նկարները հանրային չեն։

## Պատվերներ

`order.html` ձևը տվյալները պահպանում է `data/orders.json` ֆայլում։ Սա JSON ֆայլային պահեստ է, ոչ SQL բազա։ Պատվերը հաջող է համարվում միայն սերվերից 201 պատասխան ստանալուց հետո։ Կատարեք պարբերական պահուստավորում։

## Հոսթինգ

Ընտրեք Node.js աջակցող հոսթինգ, միացրեք HTTPS, նշանակեք `ADMIN_PASSWORD`, `NODE_ENV=production`, ապահովեք մշտական պահեստ `data/` և `uploads/` պանակների համար։ Նախքան հանրային գործարկումը ավելացրեք WAF/rate limiting, պահուստավորման պլան, գաղտնիության քաղաքականություն, ձեր իրական դոմենը, sitemap և իրական լիցենզավորված լուսանկարներ։

## Սահմանափակումներ

3D կատալոգում առկա որոշ նկարներ վերցված են նախկին ցուցադրական սքրինշոթից և **պետք է փոխարինվեն սեփական/լիցենզավորված նկարներով**։ Գներ, հաճախորդների կարծիքներ կամ աշխատանքների իրական տվյալներ չեն հորինվել։ Ադմին-բաժինը սկզբնական տարբերակ է և պահանջում է անվտանգության լրացուցիչ աուդիտ նախքան հրապարակումը։
